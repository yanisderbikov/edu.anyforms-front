# edu.anyforms-front

Учебная платформа anyforms: логин → онбординг → модули курса с видео.
Дизайн взят со страницы `/course` проекта anyforms-front.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

## Как устроено

- **Без бэкенда.** «Авторизация» (e-mail → код) — заглушка, состояние в
  `localStorage` ([src/auth.js](src/auth.js)). Принимается любой код от 4 символов.
- **Mock-сервер.** Данные курса отдаются JSON'ом: dev-сервер Vite отвечает на
  `GET /api/course` содержимым [mock/course.json](mock/course.json)
  (плагин `mockApi` в [vite.config.js](vite.config.js)). Когда появится бэкенд —
  плагин убрать и настроить `server.proxy`.
- **Базовый дизайн.** Все цвета, шрифты, размеры заголовков и скругления — в
  [src/styles/base.css](src/styles/base.css). Меняем токены там — дизайн меняется во всём проекте.

## Роуты

- `/login` — вход по e-mail + код с почты
- `/onboarding` — 7 экранов знакомства с курсом (показывается один раз после входа)
- `/` — главный экран: 3 модуля, ЛК справа сверху, поддержка справа снизу
- `/module/:id` — уроки модуля: заголовок, видео (ссылки на S3 из JSON), описание
